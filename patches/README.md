# Mermaid 11.15.0 首次渲染补丁

`pnpm-workspace.yaml` 和锁文件应用 `mermaid@11.15.0.patch`。补丁只修改应用实际导入的 `mermaid.core.mjs` 依赖链，不修改图表语法、布局算法、主题或安全过滤。

- `getConfig()` 为当前配置准备一次复制计划，每次仍返回独立副本，保留上游两层复制与数组合并边界。更新配置、主题、指令或 reset 时释放旧计划。最多保留一个计划，估算上限 256 KiB；超出后使用原有复制逻辑。
- Dagre 的节点、边标签、节点定位和连线 DOM 操作每批最多 32 项，累计工作超过 8 ms 后通过 `scheduler.yield()` 让出主线程，不支持时回退到单次定时任务。单个节点和布局算法本身仍可能超过预算。
- 渲染器取消时移除自己的测量容器；Dagre 下一批检查连接状态并终止。批次闭包随本次渲染释放，没有常驻 Worker 或额外文档缓存。

`mermaidDependency.test.ts` 验证实际安装补丁的配置隔离、失效、预算回退及分批取消；`mermaidDiagramRenderer.test.ts` 验证大 SVG 阶段切换时取消与缓存清理。升级 Mermaid 时应重新核对内部配置写入路径和 Dagre 渲染阶段，再跑这些测试与原生图表复测，不能直接沿用旧补丁。

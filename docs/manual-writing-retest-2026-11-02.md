## 已记录观察

- OBS-01：普通文字、代码、表格、公式、列表、剪切粘贴及标签撤销中，多次捕获“宿主提交失败：文档 revision 已变化”红字；稳定后内容恢复。普通文字首次序列为 `abX` → Backspace → Ctrl+Z → Ctrl+Y → Home → Delete → Ctrl+Z，立即仍见b，之后恢复ab。该同序列再测一次未捕获，随后其它场景再次出现，不能因此关闭观察；不同场景不能混算一个复现率。已观察到的expected/actual包括12/13、34/35、8/9、25/26、51/52、61/62、24/25、15/16、2/3（12/13在不同文档重复出现）。这是确实出现的瞬态错误提示，未证实持久撤销失败，也未量化持续时间。
- OBS-02：初始主页 Ctrl+N 无可见响应，点击新建后成功；编辑器内 Ctrl+N 可直接创建并输入。初次主页激活状态不确定，待复核。
- OBS-03：新标题输入后，大纲短暂仍显示空标题，后续刷新为 Head；未量化持续时间。
- OBS-04：双栏输入即时截图右侧已出现x、左侧尚旧；1秒后的检查两栏一致。只能确定后续检查时同步已完成，不能称实际延迟就是1秒，也不能由静帧证明无闪烁。
- OBS-05：远处点击大纲Head后能滚回顶部，但直接x未在标题处出现；随后Ctrl+Z撤销了先前的尾标题End，并使视口回底部。焦点是否应随大纲跳转以及输入去向未完全确认；没有把这次尝试判为编辑落点通过。
- OBS-06：手写NOTE前缀与菜单创建行为不同，见未完成范围。单个星号录入粗体前缀时也曾短暂先显示列表圆点，第二个星号后恢复字面前缀；完成态粗体正确，未据此另判缺陷。

## 已确认问题

### BUG-01 / P2：粗体与斜体开关后残留交叉 HTML 标签

- 案例：F01、F02。新建空白页，逐键输入 `body`，Home、Shift+End 选中正文；依次 Ctrl+B、Ctrl+I、Ctrl+I、Ctrl+B，每步观察；End、空格后出现可见空 strong 标签，粗体按钮再次亮起。继续逐键反引号、x、反引号，再保存。
- 预期：格式全部关闭后为普通 `body`，后续空格/行内代码不产生无关 HTML。
- 实际保存的标签交叉闭合且已落盘；没有逐键输入这些 HTML 标签。正文仍存在，尚无字符内容丢失证据：

```html
<em><strong></em></strong>body `x`<strong><em></strong></em>
```

- 复现：综合样本一次，两个独立新建页的最小序列 **2/2**。新页没有综合样本中的额外 Ctrl+B，也能复现。第二轮明确在 End 后、空格之前就出现可见空标签。
- 证据：不可变 `checkpoints/BUG-01-minimal-1.md`，SHA-256 `561E8D6F1E812BBB78BE4CBB499AF4CEADD37352579783943E018788A689B42E`；第二份为 `checkpoints/BUG-01-minimal-2.md`，综合样本为 `checkpoints/F-toggle-unexpected.md`。后续测试有误点/重做，当前活动文档不冒充原始检查点。UI现象由Terra观察，持久化由主代理独立核对。
- 排查入口：`src-gpui/src/nomo_mark/inline_commands.rs` 的 `selected_with_toggle`、选区映射和标记拆分。当前只确认现象与文件结果，未宣称已定位完整根因，也未修复。

### BUG-02 / P2：逐键创建代码块多出首个空行

- 案例：C01。空白页依次输入三个独立反引号、t、x、t、一次 Enter、x。第三个反引号已经显示空代码块；输入语言后标题为 Plain Text；Enter 后光标看似第一行，输入 x 后落在第二行。
- 预期：一次 Enter 后，第一行代码为 x。实际保存为围栏 txt 后两个换行再到 x，即源码字符串 `"```txt\n\nx"`。
- 复现：引用后新建代码块一次，独立空白文档一次，2/2；独立样本 `checkpoints/code-repro.md` 为 9 字节，SHA-256 `CBA61506335750C272AF826D7D8038CE709976F3816168D48257A568CE67ECA8`。未继续排查完整根因，未修复。

### BUG-03 / P2：Details 标题末 Enter 后仍在标题中输入

- 案例：O03。UI 创建空 Details，逐键 title；确认标题末光标后 Enter，随后直接逐键 i、n，不加方向键，保存。
- 预期：Enter 进入折叠块正文，in 位于 summary 结束之后、details 结束之前。实际保存为 `<summary>titlein</summary>`，折叠块正文仍空。
- 有效定位后Enter→直接输入路径一次；此前Enter→Down→body的混合尝试仅证明body落到块外，不计作相同复现。入口失败已记录；独立新页重现及从该入口继续块内写作、退出的完整路径未验，不能写作2/2。
- 证据：`checkpoints/O-details-enter.md`，SHA-256 `DFBFD3A03280183C94441C7DBBB7B5D778352AB3B92AF7763D22031A537F4B60`。旧功能清单 C01 及当前 `editing_rules.rs` 的标题换行规则均以进入正文为预期；完整根因未定位，未修复。

### BUG-04 / P2：手写未闭合代码块的 Ctrl+Enter 无法退出

- 案例：C01→C03 的连续写作路径。新页逐键三个反引号、txt、Enter、x；保持代码内焦点，Ctrl+Enter 后输入 y。
- 预期：在块后创建普通段落，y 位于代码之外。实际 y 仍在代码第4行，中间留空行；磁盘仍是未闭合围栏，x、y 都属于代码。
- 复现：已有手写块一次、新空白页最小路径一次，2/2。菜单 Ctrl+Shift+K 创建的闭合代码块作为对照，Ctrl+Enter 在块后输入 y、Ctrl+Shift+Enter 在块前输入 z 均成功。
- 证据：`checkpoints/exit-code-repro.md`、`checkpoints/BUG-04-code-exit-2.md`；闭合对照 `checkpoints/ode-edge.md`（额外 c 是已记录的保存对话框焦点失误）。该缺陷限定于本次手写未闭合围栏入口，未推断所有代码块无法退出；未修复。

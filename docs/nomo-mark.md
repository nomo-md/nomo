# NomoMark 编辑入口与当前边界

NomoMark 是 Nomo 基于 GPUI 的原生 Markdown 编辑控件。代码模块为 `src-gpui/src/nomo_mark/`，核心类型为 `nomo_mark::view::NomoMark`；正式页面和独立开发入口共用该实现。

默认 `nomo [文件或目录 ...]` 已使用 `Workspace → DocumentHost → NomoMark`。新建、打开均建立原生文档会话，不创建完整 Buffer 镜像；尚未完成主分支页面和全部行为等价验收。

```sh
cargo build --locked --release --bin nomo
cargo run --locked --bin nomo -- /path/to/document.md
```

独立开发外壳仍保留：

```sh
cargo run --locked --features nomo-mark-demo --bin nomo -- --nomo-mark-demo
cargo run --locked --features nomo-mark-demo --bin nomo -- --nomo-mark /path/to/document.md
```

feature 仅控制开发入口、内置样本和调试界面；正式与开发入口共用窗口、事务、历史和资源代码，文档会话依赖现属于默认构建。

更名前的 `editor-control-demo` feature、`--editor-control-demo` 和 `--editor-control <文件>` 参数继续作为兼容别名；当前示例统一使用 NomoMark 名称。Roadmap 中的历史命令和 `docs/archive/` 保留当时名称及验证记录。

## 数据与生命周期

- 应用共享一个 MarkdownDocumentSessionManager；每个文档有独立 owner，避免关闭后台标签取消另一文档的查询。完整正文、编码、历史、全局修订与保存快照归会话；控件只消费局部 DocumentWindow。
- 沿用原有连续窗口、视口调度、预取、ResidentLease 字节预算和取消机制。普通新建为零字节窗口，打开按结构加载窗口，不把文件全文传给控件。正式和开发入口的首屏只等待开头约 32 KiB 的结构增量发布，全文索引继续在原会话后台构建；导航、全局命令和全文几何仍使用完整索引。
- 结构索引按会话修订推进；迟到的旧快照不能取消或替换新索引，编辑失效范围与修订门禁在同一锁内发布。窗口读取遇到修订过期、索引取消或代数失效时，保留当前输入窗口并沿现有调度重取当前修订；异步回调同时核对控件、窗口投影身份和会话修订。已提交的操作只恢复窗口与会话选区，不重复提交；真实读取或解析失败仍报告并提供重试。每个活动文档仅新增一个修订号，关闭或移交时清理，无新增正文副本、后台任务或依赖。
- 首屏结构完整时立即进行局部语义解析和渲染，不因引用定义尚未扫描到而把整个窗口降为源码。显式引用链接先显示标签及其行内格式，目标待定期间禁用跳转与目标属性编辑；引用式图片先显示替代文字，不发起资源加载。单独的 `[文字]` 候选保留字面内容，避免提前隐藏普通括号。
- 每栏只对已挂载窗口的引用键执行至多一个后台补齐查询，查询间隔至少 150 ms，每批至多 64 个键；发现定义即可更新，不等待全文索引完成。刷新复用当前正文 Arc，不新增正文镜像、文档修订或撤销记录；沿用选区、阅读锚点和交互保护，并核对 Pane、窗口、投影代数与修订。输入、隐藏、关闭及窗口重置沿用已有取消通路，补齐或失败后停止轮询；索引确认缺失时恢复正常 Markdown 解析。引用键和待定范围按当前有界窗口保存并计入驻留估算，不建立全局引用缓存。
- Workspace 负责标签、窗口关闭确认、保存对话框、自动保存和保存前快照；DocumentHost 负责窗口输入、确认、导航、错误重试与挂载生命周期。
- 切换标签、显示模式、返回主页及关闭文档时，自动收尾当前组字并提交对象草稿；已有编辑尚未确认时，沿现有状态通知接续原操作，不再弹出“窗口仍有组字、草稿或未确认编辑”要求重试。Windows 原生组字先在前台任务中请求输入法确认，避免同步回调重入编辑器更新及候选结果落入新标签。每个工作区最多保留一个待执行意图、临时订阅和组字收尾任务，新意图覆盖旧意图，完成、失败、文档移除或工作区释放时清理；不增加正文副本、独立历史或轮询任务。真实提交或草稿校验失败仍保留内容并报告具体原因，关闭时沿用未保存确认。此流程尚待真实中文输入法及桌面切换验收。
- 新文档保存、另存为和图片导入前保存共用路径默认值：已有文档使用其所在目录，未保存文档使用当前文件树目录，没有目录上下文时才使用启动工作目录；默认名称优先取当前修订的第一个 H1 的纯文本并清理非法文件名字符，无有效标题则保留原文件名或使用 `未命名.md`，索引失败时提示原因并保留手动命名保存的入口。标题按需从现有结构索引分页读取，每次只保留单页和最多 200 字节的标题文本（另加必要的保留名转义前缀及扩展名）；先等待待确认输入，查询期间修订变化则重新取标题；隐藏、关闭或释放文档取消查询，返回前校验修订和路径，不增加全文副本、标题缓存或常驻后台任务。系统保存框的实机交互尚未复验。
- 隐藏标签暂停窗口和非必要查询，保留选区/阅读位置；等待保存的目录检查可继续。关闭时显式关闭会话、detach 挂载控件并取消请求。异常释放走保留恢复资料的 detach。
- 搜索使用会话分页查询，每页最多 128 个结果；全局替换调用会话 prepare/commit。浮动大纲独立查询结构索引的折叠投影，页面最多缓存 8 页、合计 4 MiB，超限和不完整状态会显示提示；隐藏或切换文档时释放视图。统计调用既有后台统计服务，不阻塞大纲。
- 大纲可按标题层级折叠并导航，支持拖动浮层和章节；显隐、折叠和悬停使用短时动效，折叠过渡只暂存有限的可见标题并遵循系统减少动态效果偏好。章节移动通过文档会话复用正文片段并写入一次历史记录，无法安全识别的边界或标题会拒绝修改。界面、双栏交互和性能尚未实机验收。
- 大纲跳转在目标窗口已加载且布局可定位时沿用旧版 260 ms 三次缓出滚动，系统减少动态效果时为 140 ms。未加载目标在同一可取消请求中准备片段和有界分组元数据，再于首帧绘制前测量已挂载窗口，按文档占位坐标直接定位；相邻片段的交界归属于后一片段，避免把前一片段的 EOF 光标当作标题位置。新邻窗在参与阅读定位前完成测量，预量过程不覆盖正在执行的动画。源码模式仍将光标放在标题行末。连续点击从当前位置转向新标题，手动滚动、编辑、缩放、模式切换或文档隐藏会取消动画；每栏只保留一个短时插值，结束后停止请求动画帧，不增加正文副本、常驻计时器或预加载范围，沿用既有请求失效检查和驻留预算。
- 2026-10-30 Windows Release 定向桌面复测：使用 542836 字节固定纯文本、1282×821 窗口截图、浅色和 100% 文档缩放，语义模式四次及源码模式三次远处标题跳转，在连续截图中首次显示目标后均保持位置；此前语义模式约 24px 的二次位移未再复现。另用 11379 字节、45 个块的单窗口样本，三次已加载跳转均采到多个中间滚动位置并最终停稳。截图约 50–100 ms 间隔不代表逐帧验收，未精确测量动画时长；系统 DPI、多主题、双栏、媒体布局变化及性能趋势未在本次覆盖。
- 输入刷新时保留已发布的大纲、统计和阅读时间；候选结果通过文档修订和请求身份校验后整体替换。大纲按当前可见标题恢复分页位置，标题或顺序未变且位置映射完整时复用折叠投影；映射缺失、重排或标题变化回退分页重建。旧标题点击先在当前索引按身份解析，过期投影不能直接用于章节拖拽。大纲仍最多 8 页，4 MiB 预算中为刷新候选页与换帧保留 1 MiB，常驻页合计最多 3 MiB。
- 大纲与统计独立合并请求，同一修订不会因引用补齐而反复重新计时。尾部防抖为 300 ms，持续输入时至多推迟 900 ms 启动一次最新版本查询；输入仍可取消过期计算，900 ms 不是结果完成时限。统计隐藏时取消计算，非活动标签只保留六个统计数值及其修订。查询失败保留已有显示，统计重新打开时可重试。
- 全文与选区统计切换使用 160 ms 淡化和 3 px 轻移，取消选择时反向；拖动选区或打字只更新数值，不反复播放。刷新期间保留最近一次选区统计，取消选择立即恢复全文，过期请求不得覆盖当前范围。数字区域按当前文档和统计类型已出现的最大位数预留（最多 20 位），单位和相邻缩放按钮保持稳定；切换文档、隐藏统计或改变统计类型时清理过渡，系统减少动态效果时直接切换。仅保存有限计数和短时动画状态，结束后停止请求动画帧，不增加正文副本或常驻计时器；真实桌面动效尚未验收。
- 统计通过 PieceTree 的不可变源片段定位新旧修订的变化范围，不逐字节比较未变前后缀；原文字符数和行数只读取变化范围及必要的 CRLF 边界，保持 UTF-16 字符计数。语义字数和可见字符沿用块级复用；结构或引用语义无法局部确认时仍走有界完整校准，不增加全文正文镜像。
- 语义/源码和双栏共用同一个会话及历史。双栏按需增加一个 Pane，各自持有有界窗口、滚动/高度树；任一时刻只开放一个输入控件。事务确认绑定提交 Entity，窗口加载核对 Pane 身份、代数与修订；新用户意图取消旧滚动跟随。离开双栏释放另一栏，隐藏标签同时暂停两栏。
- 模式切换及双栏同步使用完整文档字节锚点；单栏内容宽度使用配置，双栏按比例自适应。超大单结构及 raw/native_region 使用约 32 KiB 的原文窗口，沿 UTF-8/CRLF 边界切分；当前片段以源码方式显示，完整结构可用后恢复请求的显示模式。上述新行为尚未通过实机验收。
- 标题栏独立 Chrome Entity 只接收活动文档状态摘要，菜单动作回到 Workspace/控件；最近记录与文档主页共用持久记录，HTML／PDF／Word 导出已经接通；其余未接通能力继续在 Roadmap 登记，禁用项不代表功能已经完成。
- 主工具栏以本地 `origin/master` 的 `339fb93` 为外观和按钮顺序参考；额外的原生命令仍可从菜单、快捷键或设置访问。支持格式状态、折叠/恢复、紧凑宽度、公式和图表选择、表格及双栏对齐线。工具栏底部不绘制分隔边框。右侧搜索、大纲和双栏对齐线按钮无常态边框；Emoji 从快捷插入访问，主工具栏不再放置入口。图标、滚动、焦点、动画和不同 DPI 的一致性尚需实机对照。
- 标题栏及二级菜单、设置下拉、工具栏选择器、链接/表格/Emoji、隐藏标签列表和文件树右键菜单共用 `ui/popup.rs`。弹层按本帧触发边界及内容实测尺寸定位，默认留出 6px 间隔，空间不足时翻转并限制高度、允许滚动；工具栏横滚和窗口布局变化后重新定位。入场为 160ms 淡入及 3px 位移，系统减少动态效果时取消位移、缩短或跳过动画。编辑区右键使用旧版专属尺寸与定位，见下方隔离实机验收。此项尚未经过完整桌面、不同 DPI 和动画视觉验收。
- 代码块与公式块保留选区方向；语义模式的普通段落会将所选可见文字转换为块正文，并拆开选区两侧的行内格式。跨窗口普通段落可分组处理格式和块转换；列表、引用及 Markdown 表格可分组处理行内格式，块转换仍会提示并保留原文。源码按 64 KiB 分片扫描；语义跨窗口选区和补丁分别受 4 MiB 预算约束，单个生成块受现有 32 KiB 语义结构预算约束。部分行内代码、HTML 等未支持的结构及超预算选区会提示并保留原文。
- 脚注和目录插入通过后台分页结构索引执行。标题修改后，目录补丁在后台合并准备，通过编辑器原有确认队列作为派生事务提交；保存先等待目录检查，再捕获该修订的快照。候选目录扫描及补丁各有 4 MiB 上限；选区位于目录内或结构不完整时保留原文，保存继续并给出提示。Emoji 目录按需加载并用虚拟列表显示；搜索面板提供全字、反向和循环选项。
- 工具栏及公式、图表、链接、表格、Emoji 和搜索浮层支持简中、繁中、英文、日文，并可读取系统语言；其余界面仍为简中，部分底层错误详情保持原语言。界面语言设置可即时切换，系统语言在进程启动后缓存。
- Windows 主窗口和设置窗口共用原生窗口按钮及拖动区域；主窗口关闭仍经过未保存确认。Markdown Mini 入口仅在有文档时显示，功能尚未接入；窗口交互和旧版视觉对照仍待实机验收。

## 编辑边界与恢复

- Shift+Enter 在语义正文中插入段内换行，使用已有 `<br>` 表示保留段尾、空段落及连续换行；普通 Enter 仍另起段落。引用正文之间保留段落分隔，正文起点按 Enter 只增加一个空行。换行前后保留真实光标锚点，尚未输入文字时也显示空行；Backspace／Delete 一次删除完整换行，兼容已有 Markdown 硬换行。源码和代码块仍按原有规则换行，真实键盘交互尚待实机验收。
- Markdown 表格单元格内的 Enter 与 Shift+Enter 使用 `<br>` 在格内换行，不再插入会拆开表格行的原文换行；复用当前窗口事务和撤销历史。HTML 表格保留原有段落／段内换行规则，源码模式仍逐字编辑；真实键盘交互尚待实机验收。
- 语义模式下，引用／提示块内的普通 Enter 使用带引用前缀的空行分隔段落，第二段输入前后保持同一段间距；Shift+Enter 仍使用段内换行。空引用／提示块内按 Enter、Backspace 或 Delete 会一次移除当前空块及提示类型标记（包括文档末尾的空块），将光标留在普通输入位置；嵌套时只退出当前这一层。已有正文、引用定义或注释的块不会整块删除；退出其末尾空引用行时保留段落分隔和外层前缀，后续输入不会重新成为原引用的懒续行。折叠块退出落点跨过已有换行，避免继续输入紧贴结束标签。Shift+Enter 保留段内换行行为；沿用当前窗口事务与撤销历史，真实键盘交互尚待实机验收。
- 语义模式将普通段落之间的两个原文换行作为一个编辑边界，Backspace／Delete 可一次合并相邻段落；源码模式保留逐字编辑。退出末尾空列表项后保留真实空段落锚点。纸面留白点击复用已挂载窗口的命中与选区通路，正文上方／下方分别定位到首尾，短行右侧优先命中同一纵向位置；交互及中文输入法仍待实机验收。
- 普通编辑预计超过 32 KiB 分组目标时，补丁进入原有确认队列，宿主提交后重新加载有界窗口；不在控件里构造扩张后的正文镜像。局部乐观投影另有 1 MiB 硬限制，组字结束后按需重新分配窗口。提交失败保留原操作身份供重试；已提交但加载失败显示重新加载入口，不重复提交编辑，也不阻止保存会话中已确认的内容。
- 非空选区改写及跨窗口输入的中文组字使用独立的 UTF-16 预编辑坐标和至多 64 KiB 的临时文字。确认前保留原选区，取消不修改正文；确认后将替换作为一笔会话事务提交。局部确认复用语义命令处理表格转义和源码映射；预编辑文字和布局随确认、取消或控件释放清理，不缓存旧视图或完整选区正文。
- 原文窗口只做局部源码布局，不把截断结构解析为完整 Markdown。窗口边界的删除由宿主加载相邻有界片段后提交；滚动加载失败在对应位置显示错误及重试按钮，错误记录随视口回收或窗口重置清理。
- 正文语义模式在当前窗口的显示投影中保留行尾和纯空白行的空格及精确源码映射；这些空格参与排版、光标、选区与点击定位，原文和 Markdown 结构语义保持不变。沿用现有窗口与布局生命周期，桌面交互尚待实机验收。
- 语义表格中的链接始终显示标签，选中时不显露目标地址；工具栏链接弹层可编辑地址，源码模式保留完整语法。Ctrl/Cmd 单击可打开网页、邮件、文内锚点或本地 `.md` / `.markdown` 文档。本地路径相对当前文档解析，支持 URL 编码、绝对路径、`file:` URL 和文件后锚点；复用已有标签，新文件按原有窗口会话打开，等待打开完成后定位。未保存文档的相对链接、远程文件主机和不支持的协议会提示原因。

## 图片预算、键盘与布局

- 图片先检查编码文件不超过 32 MiB、单轴不超过 32,768、总像素不超过 16,777,216，并检查解码输出字节；解码器分配提示为 64 MiB。上传前同时限制最长边 2,400 和总像素 4,194,304，保留原始尺寸用于布局。GIF 最多 256 帧且全部帧位图合计不超过 32 MiB；超预算明确失败，不静默丢弃后续帧。可见正文按帧延时播放，减少动态效果时显示首帧；没有后台动画计时器。SVG 输入另限 2 MiB，复用 resvg 和字体数据库；拒绝内嵌或外部图片引用，栅格化沿用位图预算。最多同时解码 2 项、排队 64 项；共享位图缓存仍为 256 MiB，淘汰时同步清理窗口 atlas。上述数值不是进程或 GPU 总内存上限，解码器临时内存与缩放中间结果需单独观察。
- 路径状态最多 512 项、估算 512 KiB；近期失败另存最多 2,048 个固定大小的哈希记录，含索引约 192 KiB，避免路径状态淘汰后立即重复解码坏图片。失败和超预算原因显示在图片占位文字中。共享队列只持有路径，任务完成后继续处理下一项，不持有旧控件或组件回调。
- Windows/Linux 接入 Ctrl+方向键按词移动、Ctrl+Shift+方向键按词选择、Ctrl+Backspace/Delete 按词删除、Ctrl+Home/End 文档首尾及扩展选区；macOS 对应使用 Option 按词、Command 按行或文档移动及删除。两侧均接入 PageUp/Down、Shift+PageUp/Down 和视觉行 Home/End。IME 和对象草稿期间不移动宿主选区；原子对象按可见边界处理，不能安全删除隐藏语法时保留原文并提示。
- 跨窗口键盘边界只读取约 64 KiB 上下文，超过预算保留选区；删除仍提交一笔原有会话事务并保留模板更新。上下行和翻页复用高度索引选组，未加载组使用估算高度，窗口完成布局后再定位并保持扩展选区锚点。文档首尾直接加载目标窗口，不拼接全文。
- 布局只跟踪当前窗口实际查询的图片和公式资源，依赖集合最多 512 项、估算 256 KiB；超出时该窗口退回全局资源代数判断。正文编辑仍重建当前片段的显示列表与源码映射，规格一致的段落通过上一帧弱引用复用塑形结果；临时索引最多 1,024 项，随本次布局结束释放，不保留旧正文或另建段落缓存。选区矩形和行内对象绘制只处理可见行，行宽在布局完成后记录，行定位使用二分查找。
- 本轮没有新增依赖或修改撤销历史容量。键盘、图片和布局的桌面行为、三轮性能对照及 macOS/Linux 实机结果仍待验收；编译和既有测试通过不代表已完成这些验收。

## 帧耗时采样与百万字基准

`NOMO_FRAME_PROFILE=<输出 JSON>` 显式启用帧采样（`src-gpui/src/frame_profile.rs`），未设置时不分配、不加锁。记录两类样本：工作区一帧从 `render` 开始到常规绘制结束的 CPU 耗时（`frame`），以及按键或派发动作到其后首个绘制完成帧的延迟（`input_to_paint`）。样本各保留最近 16,384 条，每 240 帧覆盖写一次中位数、p95 和最大值，不记录正文或路径。两项均不含 GPU 提交与垂直同步等待，不能直接等同于屏幕实际上屏时间。

附加 `NOMO_FRAME_PROFILE_PAGES=<次数>` 时，打开后等待 4 秒（等待期的空帧不计入），再每帧向焦点文档派发一次 `PageDown`，最后一次翻页上屏后写最终汇总并停止采样，用于无人值守的同场景前后对照。样本文档由 `scripts/gen-perf-doc.py` 按固定种子生成（默认约 100 万字符，混合标题、段落、行内格式、列表、待办、引用、提示块、代码块和表格）：

```sh
python3 scripts/gen-perf-doc.py /tmp/nomo-perf/million.md
NOMO_FRAME_PROFILE=/tmp/nomo-perf/r1.json NOMO_FRAME_PROFILE_PAGES=300 target/release/nomo /tmp/nomo-perf/million.md
```

目标：百万字文档滚动帧与按键到上屏的中位数均不超过 5.7 ms（参照同类 GPUI 文档客户端公开的中位数），p95 不超过 8.3 ms（120 Hz 单帧预算）。

# Nomo Markdown V1：结构索引迁移契约

状态：已选定 pulldown-cmark 0.13.5。桌面正文宿主、大纲面板、脚注交互、标题锚点和自动目录已接入原生服务；本轮定向检查、Tauri 开发交互、七种负载前后三轮 Release 资源对照及各 20 次切换/关闭重开已完成。精确时延和完整交互矩阵仍待验收，不能据此宣称整体方案完成。

## 支持范围与权威来源

- 项目仅支持桌面；开发、交互验证使用 `pnpm run tauri dev`。
- 迁移完成后 Rust 是完整结构索引的唯一正式实现；前端只解析可见块并负责编辑和布局。
- JS 全文结构扫描器只在迁移对照或现有测试仍需要时暂留，不设计正式回退或浏览器同步实现。
- 本项覆盖结构、大纲、引用式链接、脚注、标题锚点、自动目录及现有消费者；不扩展到章节重排原生化或跨文件知识图谱。

## 语法层次

| 层次 | 契约 |
|---|---|
| 基础 | CommonMark 0.31.2 |
| GFM | 表格、删除线、任务列表、扩展自动链接、禁止原始 HTML 标签过滤 |
| Nomo | Front Matter、Callout、Details/Summary、目录标记、脚注、公式、上下标、图片属性和现有 HTML 分类 |

GFM 基础版本与 CommonMark 0.31.2 不一致时以选定 CommonMark 基础规则为准；只对明确清单作符合性声明。不得直接启用解析器全部扩展。HTML 过滤不替代现有安全呈现。

语法变化必须列出输入、旧结果、新结果、原因，并同步前端局部解析。不得通过无提示删除语法支持或扩大源码降级范围使迁移门槛通过。

## 必须保留的产品语义

- 来源坐标为原文 UTF-8 字节范围；CRLF、转义、实体、中文及 emoji 不得通过预替换破坏映射。
- Front Matter、Details、TOC 和嵌套容器必须由可信的完整边界决定发布，不能把读取页当成语法单元。
- 标题内容沿用当前可见文本契约，图片属性不进入标题，code 内符号按字面量处理。全局 slug 保留现有去重／空标题回退规则。
- 块身份、编辑投影身份与 slug 分开；局部修改不能为未变前后缀重新生成身份。
- 引用式链接采用全局首次有效定义；片段内的后续定义不得遮蔽它。未解析引用也登记依赖，新增定义后才能正确失效。
- 脚注、链接标签和标题锚点使用独立命名空间。脚注定义支持跨窗口查询，保留 Nomo 标签展示；标题改名不自动改写正文链接。
- 自动目录只从同修订、相关标题语义完整的索引派生；保留原目录、换行、派生历史及选区映射。
- 原始扫描完成与语义完整分别表示；超大块保留原文，不将缺少已解析标题解释为“没有标题”。

## 原生接入约束

- 复用现有 Markdown 会话、不可变快照、窗口 owner 和 revision 校验。计算不得长期持有会话锁。
- 分片计算支持取消、过期结果丢弃、隐藏文档暂停和多可见文档优先级；关闭、移交、detach 全部有清理路径。
- 新增查询协议统一携带 documentId、revision、indexGeneration 和 syntaxVersion；游标不可跨代复用。
- Rust 提供正文范围、几何摘要、大纲视图、目标解析、变更摘要和自动目录派生接口。
- 正式扫描正文 IPC 为零；前端详情按页查询，不能以返回完整元数据数组代替原生化。
- 初始预算：前端每窗口新增索引缓存 8 MiB（几何摘要含在其中且最多 1 MiB）；Rust 页缓存全进程 32 MiB；派生磁盘全进程 512 MiB；单页 256 项且最多 256 KiB。
- 单次语义候选沿用 32 KiB 边界；解析器瞬时分配与页缓存分别计量，不能将它们混作同一上限。
- 更新期间大纲保留上一版、折叠与滚动位置，当前编辑标题局部反馈，随后由 Rust 校准；过期点击／拖拽须解析当前目标。

## 阶段 0 产物与门槛

实验入口：`scripts/structure-index-evaluation/run.ps1`。实验直接引用应用目录中的共享适配器；正式应用仅依赖选定的 pulldown-cmark，不引入另一个候选。

实验覆盖规范样例、Nomo 对照、全局定义优先级、来源坐标、分块、范围收敛、取消边界和片段分配成本。原始 JSON、哈希、环境和报告写入指定产物目录。

当前选型证据：CommonMark 652/652、所选 GFM 扩展 24/24 通过 DOM 等价比较；49/49 组 Nomo 结构、标题、定义、读取分块对照通过；原生适配器包含巨型块、转义、未解析依赖和 slug 回归。选型通过只允许进入原生服务阶段，不能代替应用迁移验收。

语义调整记录：输入 ``x^`a^b`^`` 及其后续行内内容，旧规则将代码中的 `^` 当作外层结束符，可能导致后续反引号错配；新规则保留代码中的字面 `a^b`，外层格式使用代码之后的结束符。原因是代码内容没有格式定界语义。Rust 标题适配与前端局部 tokenizer 已同步；不主动改写文件。

选型出口：只有一个候选满足全部硬门槛时选该候选；多个通过时比较适配复杂度、资源与时延；无显著差异优先 pulldown-cmark。没有候选通过则保留差异报告并重新讨论内核，不切换生产链路。

当前存储实现使用一个按需打开的进程共享 SQLite pager（rusqlite 0.40.2，固定锁文件），缓存目标 24 MiB、SQLite 总堆硬限 32 MiB。主库限 255 MiB，为回滚日志和页头预留空间，使派生文件总额度保持在 512 MiB 内。源块保存不可变事实；位置变化通过共享片段映射表达。该额度不是 Rust 或应用进程内存上限，解析器临时分配另计。

派生库使用会话独有路径，进程结束后不跨进程恢复，`synchronous=OFF` 避免每个可取消片段等待持久化；保留 DELETE journal 的运行时事务回滚。此设置只影响可重建的结构数据，不改变原文保存。块发布复用 prepared statements；前台 request/demand/query 等待当前批次完成后先于下一批后台构建执行，避免可见查询被持续构建饿死。

### 已落地且有回归覆盖的服务行为

- 前部标题编辑只重扫安全检查点到实际源文相同的收敛块；约 45 KiB 用例读取少于 32 KiB，未变后缀使用位置映射，身份和内容版本保留。
- 没有共享旧片段的全量构建，按最多 256 项直接发布扫描时已确定的 slug，避免再次逐标题去重；有共享片段的增量构建继续执行碰撞传播和收敛校准。前端尚无首批结构时按 16 ms 查询，出现可见前缀后恢复 80 ms 后台轮询。
- 删除首次有效引用定义后采用后续定义；撤销、重做后的块范围、层级、标题文本/slug、定义和依赖与完整重建一致。
- 标题身份查询使用 `blockId:blockHeadingIndex`，与 URL slug 查询分开；结果带当前章节范围。未完成校准时不返回可供导航的临时 slug。
- 独立大纲视图在原生保存折叠投影，分页最多 256 行；旧折叠游标被拒绝，关闭释放句柄。前端模型保留上一可读窗口并拒绝迟到响应，创建期间销毁也会收回迟到句柄。
- 安全检查点早于实际编辑块时，回扫的未变前缀经类型、边界、摘要及原文校验后保留身份。派生目录历史恢复的跨块失效利用共享源片段证明单标题块及标题起点对应；临时映射最多 4096 段（128 KiB），发布后释放。来源重叠、超预算或拆分/合并不能证明对应时分配新身份，不按标题文字猜测。
- 局部正文消费者只获取覆盖块、该块标题和所需有效引用。定位查询不命中前端缓存，必须重新通过原生的 owner/revision 校验。
- SQLite 容量不足时构建事务回滚，保留上一已发布版本；源码降级或容器深度受限分别上报语义不完整，不能据此确认目标不存在或生成部分目录。

### 消费方接入

- `NativeMarkdownStructureIndex` 为宿主提供兼容视图，只含粗几何摘要和当前详情，不把全文块/标题下载为前端数组。查询缓存、保留的大纲页、活跃结构详情共享 8 MiB 估算字节账本；几何摘要受 1 MiB 子预算约束。该账本不等于 JS 堆或进程总驻留上限。
- 大纲面板直接读取 Rust 的可见行投影，更新中保留旧行；本地 PM 事务映射既有身份，为新增标题分配本地身份，并同步投影增删、文本和级别。投影不等待 IPC，不生成权威 slug；有未校准投影时不执行章节拖拽。稳定行锚点和跨页父项位置由 Rust 查询。章节重排仍属于显式 JS 变换。
- 可见正文注入全文有效链接定义；扫描从未完成转为完成时丢弃旧局部详情，重新查询文末定义。脚注预览最多读取 8 KiB，不递归创建交互节点；跳转和返回在原生解析全局目标。
- 原生目录保存原始片段及标题签名，保持原换行、原目录恢复和派生历史；事务复用归属/修订/编辑代次门禁和操作幂等性。保存、导出冻结前等待物化成功，语义不完整明确失败。普通打开不规范化目录。
- 历史和派生事务之后仍显示的旧 DOM 不能覆盖新修订全局选区；新索引尚未覆盖现有窗口时继续保留正文。
- 共享几何详情替换后，宿主按当前字节边界重新绑定挂载范围；粗摘要和旧修订暂停块级实测，不把旧 DOM 的高度写入新块。更新前阅读锚点保留到新 DOM 校准结束。双栏滚动由真实导航输入决定主栏，布局产生的从栏滚动不能反向接管。
- 组合标签换容器时同步解除旧绑定，再异步完成 flush/dispose；先挂新容器、后清理旧容器的顺序同样适用于源码栏。旧大纲字节位置在正文未同步或修订不一致时不参与局部源码定位。
- 原生目录返回有界编辑范围及插入字节数；未相交窗口仅重定位，不重建编辑器。相交窗口重新读取有界正文。全局选区沿用局部事务的精确 `selectionAfter`，避免整块替换的边界映射把光标移到标题末尾。
- 变更查询保留上一发布代到当前代的范围、共享片段映射、有效引用变化和大纲变化；集合或编码字节超限返回整代失效。引用反向依赖包括尚未解析成功的使用点；前端仅复用经过源文验证且不在失效范围的有界详情。
- 密集标题详情查询按视口目标优先，每范围最多 128 块、每宿主最多 256 块；标题查询只覆盖实际选中的详情范围，未选中部分保持粗几何。该约束修复了 1000 标题负载中源码范围很短但块数量过多导致共享预算耗尽的问题，不改变语义源码降级边界。

语义调整记录：`www.commonmark.org`、`foo@example.com` 等所选 GFM 扩展自动链接，旧前端局部 tokenizer 保留普通文本，Rust 已识别为链接；前端现按相同边界生成链接，并保留原始裸链接写回。普通正文编辑不会改写为显式 Markdown 链接。原有安全打开协议限制继续生效。规范对照覆盖表格、删除线及自动链接的结构事实，任务复选框与 HTML 安全呈现仍由对应现有模块负责。

### 验收覆盖与边界

1. 差异 SQL 已按最多 64 项事实分批，长语句通过 SQLite progress handler 中断；取消标志独立于服务状态锁，slug 碰撞循环也显式检查。增量 slug 共享未变化区间，仅重算编辑范围及碰撞传播涉及的名称；章节范围按当前位置映射查询。1000 个无关后缀标题的改名样例仅重算 1 个标题，36 组碰撞／空标题／层级样例与重建一致。
2. 目录直接相交窗口仍使用有界重建，未相交窗口保留 DOM。实机覆盖标题光标、跨标签选区、双栏远端编辑/历史、组合语义/源码宿主及脚注跨正文窗口定位；这不是对任意复杂选区组合的穷举证明。
3. 实际进程驻留、提交、JS 堆及 GPU 与估算缓存预算分别报告；不把缓存额度解释成进程总上限。巨型块仍明确采用有界源码模式。
4. 七种固定负载前后三轮、输入与配对切换三轮、两版各 20 次切换/关闭重开及 20 轮构建中关闭/移交/detach 自动化均有原始记录。三轮分布不代表 P99，也不构成长时间泄漏证明；收益因负载而异，完整结果见 `.artifacts/native-structure-final-20261024/REPORT.md` 和 `PERFORMANCE.md`。

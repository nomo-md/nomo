# Word 导出

通过「文件 → 导出 → 导出 Word」将当前 Markdown 文档导出为 `.docx`。组合标签只导出当前活动成员，TXT/JSON 不进入此流程。导出使用输入提交后的快照，后续切换标签或修改正文不会改变该文件；导出也不会保存或清除 Markdown 的未保存状态。

## 内容和样式

- 标题、正文、行内格式、编号列表、表格、代码、链接及脚注使用 Word 原生内容。任务列表保留勾选符号。
- 已有目录生成可点击静态目录，不生成页码；标题使用 Heading 1–6，可用于 Word 导航窗格。
- 图片内嵌；PNG/JPEG 保留原格式，SVG/WebP/GIF 转 PNG，GIF 使用首帧。公式和 Mermaid 使用固定浅色样式转为 PNG。
- 引用、Callout 和注释保留文字；编辑器支持的 HTML 按语义转换，其余 HTML 保留源码并提示。Front Matter 不进入正文。
- A4 纵向、页边距 20 mm、正文 11 pt、1.5 倍行距；中文宋体、西文 Calibri、代码 Consolas 9 pt。字体不嵌入，实际分页和缺失字体替换由 Word/WPS 决定。

## 失败和资源边界

本地图片基于原 Markdown 路径解析，未保存文档的相对图片无法解析时会保留替代文字。远程图片有 8 秒请求超时，跨域限制不通过代理绕过。图片、公式或图表无法转换时保留替代文字或源码，并在成功提示中报告降级；前三项详情显示在提示中。

导出库按需加载；每次导出单独创建 Worker 进行 DOCX 组装和压缩。媒体缓存只存活于该任务，总预算 128 MiB；单个 Canvas 上限 1600 万像素。超过预算时整个导出失败，不输出截断文档。

保存对话框取消时不生成文档。目标必须为 `.docx`，不会在确认路径后偷偷改名。完整文件经 Tauri 原始二进制传输，再使用同目录临时文件原子替换；目标占用等写入失败不会破坏原文件。窗口销毁取消尚未进入写入阶段的任务。

## 验证边界

自动检查覆盖 DOCX 内部 XML/媒体关系、快照归属、取消与失败释放、资源预算和原子保存。浏览器中的生成检查不能替代 Word/WPS 实际打开、Windows WebView2 输入法或 macOS WKWebView 验收。

实机验收使用相同 Release 构建、文档、主题、窗口与 DPI，覆盖语义／源码／双栏／组合标签，包含未保存编辑、中文输入法、屏幕外图表与图片。按项目基准执行三轮重复导出各 20 次，分别记录 JS 堆、原生内存与操作响应，不能将这些指标相加或用一次采样认定泄漏。

# 编辑器恢复逐项验收清单

整理日期：2026-10-29

本清单整理自本轮对话列出的 72 项核对内容，保留 A01–J04 编号，便于逐项反馈和追踪。它记录的是验收目标，初始全部为待核对；只有实际验证通过后才勾选，代码实现、编译和自动化测试通过不能代替实机验收。

所有功能继续使用当前窗口化机制、文档会话和撤销历史。引用／提示块固定使用现代样式，移除样式选择设置。相关实现说明见 [NomoMark 文档](nomo-mark.md)。

## A. 插入与基础编辑（7 项）

- [ ] **A01 块后可继续输入**：分别插入表格、代码块、公式、图表和块级图片，确认其后有可输入的段落，光标可进入并继续输入。
- [ ] **A02 文档末尾虚拟空行**：打开以块节点结束的已有文档，确认末尾可放置光标；仅打开或移动光标不会把文件标记为已修改。
- [ ] **A03 末尾输入与撤销**：在虚拟末尾空行输入文字，再撤销，确认输入文字和自动补入的分隔换行作为同一操作回退。
- [ ] **A04 块前／块后快捷键**：确认 Ctrl+Shift+Enter 在块前插入段落，Ctrl+Enter 在块后插入段落；在表格内按对应快捷键时执行表格插行规则。
- [ ] **A05 标题级别**：确认 H1–H6 标识显示正确，调整标题级别后显示和保存内容一致。
- [ ] **A06 标题开头回车**：在标题正文开头按 Enter，确认标题前插入普通段落，原标题及其内容保留。
- [ ] **A07 分隔线与三击选择**：确认已有分隔线可以通过对应动作取消；三击正文能够选中相应段落／块。

## B. 表格（15 项）

- [ ] **B01 工具栏图标与提示**：逐个核对表格工具栏图标和悬停提示，确认各操作可区分且含义对应。
- [ ] **B02 行增删**：分别在首行、末行和中间行添加／删除行，确认位置正确，其他单元格内容保留。
- [ ] **B03 列增删**：分别在首列、末列和中间列添加／删除列，确认位置正确，其他单元格内容保留。
- [ ] **B04 边缘控件位置**：使用多行内容、不同列宽和横向滚动的表格，确认边缘行列控件与实际单元格几何位置对应。
- [ ] **B05 列对齐**：切换左对齐、居中、右对齐，确认渲染正确，保存并重新打开后仍保持。
- [ ] **B06 表头切换**：启用／关闭表头，确认样式和保存结构正确，单元格内容不丢失。
- [ ] **B07 尺寸选择器**：悬停时显示正确行列数，选择后得到对应尺寸；缩小时保留目标范围内的内容。
- [ ] **B08 删除整表与撤销**：删除整张表格后撤销，确认结构和内容完整恢复。
- [ ] **B09 矩形选区**：跨单元格拖动，确认矩形选区范围、高亮和拖动方向一致。
- [ ] **B10 单元格复制／剪切**：复制或剪切矩形选区，确认剪贴板内容按网格组织；只有写入剪贴板成功后才删除原内容。
- [ ] **B11 清空与格式化选区**：清空所选单元格或对选中内容应用格式，确认只影响选区内内容。
- [ ] **B12 TSV／HTML 表格粘贴**：从表格或电子表格复制多行多列内容后粘贴，确认映射正确，并按需扩展目标表格行列。
- [ ] **B13 来源合并单元格**：粘贴带合并单元格的支持范围内 HTML 表格，确认合并结构保留；Markdown 目标表格按需转换为支持的原生 HTML 表格。
- [ ] **B14 部分覆盖目标合并单元格**：粘贴区域只覆盖目标合并单元格的一部分时，确认区域外应保留的内容不被误删。
- [ ] **B15 弹层与预算边界**：在窗口底部和窄窗口操作表格菜单／尺寸选择器，确认可见且可用；超出处理预算时保留原表格并显示错误。

## C. Details 折叠块（6 项）

- [ ] **C01 标题进入正文**：在 Details 标题中按 Enter，确认光标进入正文。
- [ ] **C02 正文开头退格**：在正文开头按 Backspace，确认返回标题，不误删折叠块结构。
- [ ] **C03 末尾空行退出**：在正文末尾空行按 Enter，确认光标退出折叠块并可在后方继续输入。
- [ ] **C04 默认展开状态**：切换默认展开／折叠状态，保存并重新打开后确认状态保持。
- [ ] **C05 解除折叠块**：执行解除包裹操作，确认标题和正文内容保留。
- [ ] **C06 删除与撤销**：删除 Details 后撤销，确认标题、正文及展开状态恢复。

## D. 代码块（9 项）

- [ ] **D01 进入与光标位置**：通过点击和方向键进入代码块，确认光标位于预期位置。
- [ ] **D02 语言与高亮**：选择代码语言并核对默认语言，确认高亮与语言一致，保存后的语言标记正确。
- [ ] **D03 缩进设置**：分别使用 2 空格、4 空格和 Tab 设置，确认 Tab／Shift+Tab 的缩进及反缩进符合设置。
- [ ] **D04 快捷键退出编辑**：确认 Ctrl+Enter 保存并进入下方段落，Ctrl+Shift+Enter 保存并进入上方段落。
- [ ] **D05 取消编辑**：在具有草稿的代码编辑流程中按 Esc，确认取消未确认的编辑并返回正文。
- [ ] **D06 失焦保存**：点击其他正文或让焦点离开代码编辑区，确认修改保存，焦点位置合理。
- [ ] **D07 复制代码**：复制完整代码，确认内容不混入界面文字或行号。
- [ ] **D08 长代码折叠**：折叠／展开长代码块，确认内容完整，光标和滚动位置合理。
- [ ] **D09 围栏安全保存**：在代码正文中输入与围栏相同的字符序列，保存后确认自动采用安全围栏长度，不截断代码块。

## E. 引用／提示块（3 项）

- [ ] **E01 统一现代样式**：确认普通引用及五种提示块均使用现代样式。
- [ ] **E02 移除样式设置**：确认设置中没有经典／现代样式选项；已有配置中的旧经典样式值不再影响显示。
- [ ] **E03 提示类型切换**：逐一核对 NOTE、TIP、IMPORTANT、WARNING、CAUTION 的图标、颜色和名称；切换类型后正文保留。

## F. 公式／图表（6 项）

- [ ] **F01 编辑态与预览连续性**：对照旧版单击块公式／图表，首帧即为原位“源码在上、预览在下”，无临时弹层、通用标题或确认／取消按钮；已有图表不先变空白、加载提示或缩略图。连续输入约 200 ms 停顿后更新预览，等待期间保留完整旧预览，失败明确显示错误，旧请求结果不会覆盖新内容；重复进入／退出 20 次，分别记录即时画面和稳定画面，不用静态截图证明完全无闪烁。
- [ ] **F02 方向键进出**：通过方向键进入公式／图表编辑区，在首行／末行离开；相邻内容位于其他加载窗口时仍能正确衔接。
- [ ] **F03 图表全屏入口**：分别从正文图表和编辑预览打开全屏，确认显示的是对应图表。正文放大按钮应位于块顶部工具栏右侧，图标在按钮背景内居中；小图、宽图、横向滚动、窄窗口和文档缩放时位置稳定，不覆盖图表节点，也不随位图边缘漂移。

2026-10-30 定向实测：图表进入／Esc 共 20 轮，加上空公式补修后的 5 轮，可取得首帧未见占位、图消失或缩小；三条空公式插入入口及清空后的回点编辑通过。展示态／编辑态放大返回、宽图横滚按钮定位及稳定 150% 下放大返回通过。缩放过程中仍可见加载占位；逐帧录像、真实 IME、窄窗口、多 DPI 和旧版像素对照未覆盖，因此 F01／F03 保持整项未完成。构建和逐项范围见 `docs/native-build.md` 对应记录。
- [ ] **F04 全屏显示模式**：切换可读、适应窗口和原始大小模式，确认尺寸及位置符合模式含义。
- [ ] **F05 全屏缩放与平移**：核对缩放、拖动平移、滚轮平移和 Ctrl+滚轮缩放，确认操作不会同时作用于底层文档。
- [ ] **F06 全屏关闭与返回**：通过 Esc 和关闭按钮退出；从编辑草稿进入全屏时，确认退出后返回原草稿，内容保留。

## G. 图片／上传（12 项）

- [ ] **G01 图片查看器**：双击图片打开查看器，核对缩放、平移、重置和关闭。
- [ ] **G02 图片属性**：编辑 src、alt、title、宽度和对齐，确认显示正确，保存并重新打开后保持。
- [ ] **G03 图片右键菜单**：逐项核对查看图片、编辑图片属性、复制图片地址和删除图片。
- [ ] **G04 图片粘贴**：分别粘贴截图／位图和复制的图片文件，确认通过图片导入流程插入。
- [ ] **G05 图片拖放**：分别拖入单张和多张图片，确认插入位置对应鼠标落点。
- [ ] **G06 本地导入策略**：核对三种本地图片策略；未保存文档采用本地导入时先完成文档保存，再继续插入。
- [ ] **G07 批量与部分失败**：批量导入中混入无效图片，确认有效项按顺序插入，失败项有提示，成功部分不丢失。
- [ ] **G08 远程图片**：核对 HTTP(S) 图片加载及失败占位；加载失败或等待期间编辑器仍可使用。
- [ ] **G09 PicGo Server**：配置并上传图片，确认返回的图片地址正确插入文档。
- [ ] **G10 PicGo-Core**：核对命令和配置文件设置，确认上传成功后插入正确地址。
- [ ] **G11 取消与过期落点保护**：在导入／上传过程中取消、等待超时或改变选区、标签、文档路径，确认结果不会插入过期位置。
- [ ] **G12 输入大小限制**：核对单批最多 32 张、单图编码数据最多 32 MiB、剪贴板图片数据合计最多 64 MiB 的边界；超限时有明确提示并保留原文。

## H. 剪贴板（4 项）

- [ ] **H01 Markdown 复制设置**：切换 `copyMarkdownSyntaxEnabled`，确认纯文本剪贴板内容符合设置，富文本格式仍保留。
- [ ] **H02 跨窗口复制／剪切**：选区跨越加载窗口时，确认复制／剪切内容完整，且只有剪贴板写入成功后才删除原文。
- [ ] **H03 HTML 粘贴**：核对支持范围内的标题、列表、强调、链接和表格粘贴结果。
- [ ] **H04 纯文本与源码模式**：确认 Ctrl+Shift+V 按纯文本粘贴；源码模式保持原文编辑语义。

## I. 脚注／卡片／统计／保存（6 项）

- [ ] **I01 当前窗口脚注预览**：悬停脚注引用，确认显示对应定义的预览。
- [ ] **I02 跨窗口脚注预览**：定义位于其他加载窗口时仍可预览；关闭提示或转到其他引用后旧请求及时失效。
- [ ] **I03 脚注往返导航**：跳转到定义后返回引用，确认落点正确。
- [ ] **I04 目录与摘要卡片**：核对目录链接、注释和 Front Matter 摘要卡片及其编辑入口，确认修改保存为正确源码。
- [ ] **I05 选区统计**：选择文本后显示对应统计，清除选区后恢复文档统计；过期计算不会覆盖当前结果。
- [ ] **I06 保存时清理空模板**：保存仅清理有明确模板来源的空内容，不误删手写语法；自动清理能够撤销。

## J. 共用回归（4 项）

- [ ] **J01 统一撤销／重做**：核对代码编辑、批量图片插入和表格粘贴的撤销／重做，确认每项操作遵循预期事务边界并使用同一文档历史。
- [ ] **J02 标签与双栏状态**：切换标签和单栏／双栏，确认内容、选区、阅读位置、修改标记及撤销历史保持正确。
- [ ] **J03 中文输入法**：在正文、代码、公式和表格中使用中文输入法，确认不丢字、不重复输入，组字过程正常。
- [ ] **J04 显示与窗口化生命周期**：核对浅色／深色主题、窄窗口和不同 DPI；大文档继续有界加载，关闭视图或草稿后释放对应临时状态。

## 已知边界

- 未启用／实现自动删除未使用的本地图片。
- HTML 粘贴只覆盖已支持的结构，不承诺完整保留任意网页样式。
- 撤销图片插入不会删除已经复制到资源目录中的图片文件。
- 本文是逐项验收目标，后续代码调整需结合核对时的构建确认；未勾选不等于已确认存在缺陷。

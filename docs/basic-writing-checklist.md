# 基础写作逐键验收清单

更新：2026-11-02。先执行 [真人写作测试方法](manual-writing-test-method.md)。**下表的文字样本必须逐字符按键输入，符号一步一检查**；不预先生成正文文件。状态和证据写入每轮报告，本文不保存跨构建通用“通过”结论。

## 新建、输入、修改

| ID | 动作与最小样本 | 必查结果 |
|---|---|---|
| W01 | Ctrl+N 后逐键 `abc` | 默认焦点可输入、首字符和光标正确 |
| W02 | `one two`，方向键、Home/End、Ctrl+Left/Right、正反 Shift 选区 | 字符/词/行边界与选区方向正确 |
| W03 | 选择短词后输入 `X`；Backspace、Delete；撤销/重做 | 仅目标内容被替换/删除，光标与恢复正确 |
| W04 | 两段 `one` / `two`；Enter、Shift+Enter；段首退格和段尾删除 | 段落/软换行有区别，合并和撤销不丢内容 |
| W05 | 全选本测试文档、输入短词、撤销/重做 | 全文替换历史和光标正确，不影响其它标签 |
| W06 | 普通正文后逐个输入括号、引号及 `.,:;!?+-=/@#$%^&*_~`、反斜杠、竖线和反引号 | 中间态无丢字、跳行、重复和意外吞字符；字面/语法状态可解释 |
| W07 | 真实 IME 输入拼音、选择候选、提交；再次组字并取消 | 候选/组字真实发生，提交一次、取消无残留 |
| W08 | 对自己逐键写出的文字复制/剪切，普通粘贴/纯文本粘贴并撤销 | 文本与格式符合对应入口；记录这是剪贴板测试 |

## 标题和行内结构

| ID | 动作与最小样本 | 必查结果 |
|---|---|---|
| H01 | 空段分别输入 `#`、空格、`Head`，Enter 后写正文 | 每个中间态可继续输入，标题后落点正确 |
| H02 | 标题正文开头 Enter；修改标题级别；撤销 | 标题和普通段落边界正确，原标题不丢失 |
| H03 | 分别建立短 H1/H2/H3，点击大纲往返 | 对应标题可见，编辑焦点和光标位置可核查 |
| F01 | 逐键 `**ab**`，进入/离开粗体，切换选中文字并撤销；另逐键 `body`，Home、Shift+End，Ctrl+B → Ctrl+I → Ctrl+I → Ctrl+B | 未闭合状态、结束符、格式内外输入和撤销正确；四次开关保持同一可见选区，按 End 时没有复活的格式或空标签 |
| F02 | 逐键 `*ab*`、`_cd_`，用 Ctrl+I 开关；重复 F01 的组合，用反向选区，再在末尾逐键输入空格和行内代码 | 斜体边界和标记显隐正确；保存的正文为普通 `body` 加新输入，没有交叉标签 |
| F03 | 逐键 `~~ab~~` 和反引号包裹的 `x` | 删除线/行内代码完整，符号和光标不丢失 |
| F04 | 逐键 `[a](about:blank)`，在标签内部修改，再向外移动 | 链接标记未闭合时可输入；不打开外部网页 |
| F05 | 逐键反斜杠加 `*`、方括号等转义；删除和撤销 | 转义字面值及源码一致，未误触其它结构 |

## 列表和任务

| ID | 动作与最小样本 | 必查结果 |
|---|---|---|
| L01 | 普通段落后的空行和文末分别输入 `-`，停顿，再空格和 `one` | 空前缀保持本行行高与光标，不跳上一行 |
| L02 | 同样逐键输入 `1`、`.`，停顿，再空格和 `one` | 每一步落点正确，可继续成为有序列表 |
| L03 | 独立初态的 `-` / `1.` 后分别用空格、Tab 触发 | 记录各入口的类型/缩进/源码，不将粘贴代替转换 |
| L04 | 非空项 Enter 续项；空项 Enter 退出；Undo/Redo | 续项编号、退出普通段落、结构历史正确 |
| L05 | 首项、末项末尾、末尾空项分别 Tab | 首项边界合理；末项/空子项缩进不取消列表 |
| L06 | 子项含孙项，Tab 后 Shift+Tab，再从顶层退出 | 子树随动，无重复缩进、内容丢失或错误层级 |
| L07 | 三个同级项带子列表；光标在第二项，快捷键切有序/无序/任务 | 有序/无序切最近整组父列表；子层级和已有勾选保留；任务范围明确记录 |
| L08 | 逐键创建 `- [ ] a`，勾选，再 Enter 续项 | 方框逐符号输入正确；新任务未勾选、原项状态保留 |
| L09 | 正反方向选择两个项，Tab/Shift+Tab；跨嵌套选区 | 选区内容不被 Tab 覆盖，层级变化可撤销；超预算有明确保留提示 |
| L10 | 项首 Backspace 合并/退出；粗体或链接正文中 Enter | 相邻内容、格式、子项保留，撤销恢复；每个子场景分别记结果 |

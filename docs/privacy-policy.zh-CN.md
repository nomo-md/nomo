# Nomo 隐私政策

**生效日期：2026 年 8 月 6 日**  
**最近更新：2026 年 8 月 13 日**

感谢您使用 Nomo（以下简称“本应用”）。本应用是一款以 Markdown 为核心的本地桌面文本编辑器。本隐私政策说明本应用会访问、保存或传输哪些信息，如何使用和保护这些信息，以及您可以如何管理这些信息。

## 1. 适用范围

本政策适用于由清羽（以下简称“我们”）提供的 Nomo Windows 桌面应用。

本应用不要求您注册或登录账户。我们没有为本应用运营用于接收用户文档、建立用户档案或进行广告分析的后端服务器。

## 2. 本应用访问和处理的信息

### 2.1 您选择的文档、文件夹和图片

当您使用打开、编辑、保存、导出、文件夹浏览或插入图片等功能时，本应用会访问您主动选择的 Markdown、TXT、JSON、图片及相关文件和文件夹。处理这些内容是提供编辑、预览、保存、导出、图片管理和文件恢复功能所必需的。

除本政策第 3 节所述情形外，这些文件内容仅在您的设备上处理，不会由本应用上传给我们。

### 2.2 保存在设备上的应用数据

为恢复工作状态和提供便捷功能，本应用可能在您的设备上保存：

- 应用设置和编辑器偏好，例如界面语言、主题、快捷键、自动保存和更新检查设置；
- 最近打开文件和文件夹的路径；
- 已打开标签页、当前工作区、窗口状态和文档阅读位置；
- 未保存内容的恢复草稿、编辑恢复日志和保存前快照；
- 图片处理设置，包括您配置的 PicGo Server 地址、PicGo-Core 命令及配置文件路径；
- 已下载的软件更新包及其校验信息；
- 已运行的最高版本与待展示更新日志的版本记录，用于避免重复展示；
- 在您主动启用“开发者模式”后产生的本地诊断日志。日志可能包含操作状态、错误信息、耗时信息以及与故障有关的本地文件路径。开发者模式默认关闭。

上述信息主要保存在应用数据目录、系统临时目录或您选择的文档目录中，仅用于实现本应用功能和故障诊断。Microsoft Store 版本使用 Windows 为该 MSIX 包提供的隔离应用数据目录，不会自动迁移 GitHub 安装版的设置、最近文件、草稿或快照。恢复用的临时图片在上传流程结束后会尝试删除。

## 3. 网络连接和第三方服务

### 3.1 软件更新检查

升级后的更新日志随安装包提供，在本地展示，不会为此发起网络请求；该展示独立于自动更新检查开关。

通过 GitHub 提供的 NSIS/ZIP 版本默认在启动后检查软件更新，您可以在“设置”中关闭自动更新检查，也可以手动触发检查。更新检查会连接 GitHub Release 服务，以获取最新版本号、发行说明、更新文件信息和校验文件；只有在您选择下载更新时，本应用才会下载更新安装包。

Microsoft Store MSIX 版本的软件更新由 Microsoft Store 管理。该版本不会为软件更新访问 GitHub Release 接口，也不会下载或安装 GitHub 提供的 NSIS 安装包；应用中展示的当前版本发行说明随安装包一同提供。

在此过程中，GitHub 可能按照其隐私政策处理提供网络服务通常需要的技术信息，例如您的 IP 地址、请求时间、User-Agent 和网络日志。本应用不会在更新请求中发送您的文档内容、最近文件列表或 PicGo 配置。GitHub 对相关信息的处理受 [GitHub 隐私声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)约束。

### 3.2 远程图片

当您打开的文档包含以 `http://` 或 `https://` 开头的远程图片链接时，为显示该图片，本应用使用的系统 WebView 可能直接向图片所在服务器发送请求。该服务器可能接收到您的 IP 地址、请求时间、图片地址及常规网络请求信息。远程服务器如何处理这些信息由其运营者的隐私政策决定，我们无法控制。

如果您不希望发生此类请求，请勿打开来源不可信且包含远程图片的文档，或将远程图片改为本地图片后再打开文档。

### 3.3 PicGo 或 PicGo-Core 图片上传

图片上传不是默认处理方式。只有当您在设置中将图片插入方式切换为“上传”，配置 PicGo 或 PicGo-Core，并主动插入图片时，本应用才会把您选择的图片交给该工具或您配置的服务进行上传。

PicGo Server 通常由您在本机运行；PicGo-Core 及其图床插件可能把图片传输到您自行配置的第三方图床。第三方可能接收图片内容、文件名、IP 地址、请求时间、账户或鉴权信息，以及其服务所需的其他数据。具体处理方式取决于您选择的 PicGo 配置、插件和图床服务，请在使用前阅读相应服务的隐私政策。

您可以随时在设置中将图片插入方式切换回本地复制，以停止后续上传。停止使用上传功能不会自动删除已经上传到第三方服务的图片；如需删除，请通过相应服务提供的方式处理。

在上传包含他人个人信息、敏感信息或受保护内容的图片前，您应确认自己拥有相应权利，并已取得适用法律要求的授权或同意。

### 3.4 外部链接

当您点击文档中的外部链接时，本应用会请求系统默认浏览器或关联应用打开该链接。访问目标网站后的数据处理由该网站或应用的隐私政策约束。

## 4. 我们不进行的处理

就当前版本而言：

- 我们不要求或收集您的姓名、手机号、地址或账户资料；
- 我们不使用广告 SDK、用户行为分析 SDK、遥测服务或崩溃报告服务；
- 我们不以出售、出租或广告定向为目的使用或披露您的信息；
- 我们不会访问摄像头、麦克风、精确位置、联系人、日历或生物识别信息；
- 除您主动使用第三方上传功能、加载远程内容、打开外部链接或进行更新检查外，本应用不会将您的文档内容发送给我们或第三方。

## 5. 信息的共享与披露

我们不会从本应用接收您的本地文档和应用数据，因此不会将其提供给其他公司或个人。

仅在您使用第 3 节所述功能时，相关信息会直接提供给 GitHub、远程图片服务器、PicGo/PicGo-Core 或您选择的图床服务。我们不控制这些独立第三方的处理活动。

如果您主动向我们发送邮件、提交 Issue 或以其他方式请求支持，您选择提供的信息将用于回应请求、排查问题和维护本应用。请勿在公开 Issue 或不安全渠道中提交含有敏感信息的文档或日志。

## 6. 数据保存、删除与您的控制权

本应用保存的数据主要位于您的设备上。您可以通过以下方式进行控制：

- 在应用中修改设置、关闭自动更新检查或停止使用图片上传；
- 保存或关闭文档，以管理工作区恢复数据；
- 删除原始文档、图片、导出文件及第三方服务中的已上传内容；
- 删除 Nomo 的应用数据，以清除本地设置、最近路径、工作区信息、恢复草稿、快照、更新缓存和诊断日志。

卸载本应用不一定会自动删除操作系统保留的应用数据。GitHub 安装版的数据通常位于 Windows 用户应用数据目录中 `com.nomo.desktop` 对应的文件夹；Microsoft Store 版本的数据由 Windows 按 MSIX 包管理，可在 Windows 的应用高级选项中重置。删除前请先备份仍需保留的未保存草稿或快照；删除后这些数据可能无法恢复。

由于我们不持有上述本地数据，通常无法代您访问、更正、导出或删除这些数据。您可以直接在自己的设备或相应第三方服务中行使这些控制权。如您曾主动向我们提供支持信息，可通过第 10 节的联系方式提出访问、更正或删除请求；我们会按照适用法律处理。

## 7. 信息安全

本应用采用以下措施降低数据风险：将核心文档处理和应用状态保留在本地；仅访问实现用户所选功能所需的文件；对软件更新文件进行完整性校验；更新检查使用 HTTPS；诊断日志默认关闭。

但任何存储或传输方式都无法保证绝对安全。您的本地数据安全还取决于设备、Windows 账户、磁盘加密、备份和访问控制设置。对于您自行配置的 PicGo、图床或其他第三方服务，请选择可信服务并优先使用安全的加密连接。

## 8. 儿童隐私

本应用面向一般用户，不以儿童为目标，也不会主动收集儿童的个人信息。如果您是未成年人，请在监护人指导下使用本应用及任何第三方上传服务。

## 9. 政策变更

当本应用的数据处理方式或功能发生变化时，我们可能更新本政策。更新后的政策会通过新的公开页面或应用版本提供，并在文首更新“最近更新”日期。重大变更将按照适用法律以适当方式告知用户。

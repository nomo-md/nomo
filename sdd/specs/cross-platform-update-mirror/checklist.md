# Verification Checklist: 跨平台安装包镜像竞速与 macOS 自动更新

> 所有项目通过后才能将需求标记为 completed；未经真实桌面验收的项目必须明确保留未勾选。

## Functional Verification
- [x] 官方 Release API 正常时不请求代理元数据；失败或超时时 gh-proxy 能回退获取同一 API，双失败时不构造候选。（生产代码与白名单测试；gh-proxy 实际 API 已返回完整 Release）
- [x] 代理元数据与官方响应经过相同的版本、官方地址、资产唯一性、大小和 SHA-256 格式校验，文档明确无独立签名时的代理信任边界。
- [ ] Windows 官方安装包正常下载时没有任何 gh-proxy 请求，既有 NSIS 更新成功。（待 Windows 实机）
- [ ] 官方连接失败、可重试响应或停滞时按设计启动镜像，首个完整校验成功包生效。（状态测试通过，待真实故障注入）
- [ ] 修改镜像内容会导致大小或 SHA-256 失败，伪造文件不会被执行。（待篡改测试/实机）
- [x] 两路使用不同文件；胜者产生后另一路取消并清理，两路都失败时可重试。（生产状态测试与代码复核）
- [x] 双路进度不相加、不平均、不归零或倒退，取消同时停止两路。（生产进度状态测试与代码复核）
- [ ] macOS 正式可写安装版完成应用内下载、校验、正常退出、替换、重启和更新成功提示。（待授权的桌面验收）
- [ ] macOS side-by-side、DMG/App Translocation、异常路径和权限不足均不修改原应用，并提供手动更新路径。（待桌面验收）
- [ ] macOS 路径穿越、链接、错误 bundle、错误版本/架构和无效 codesign 包均被拒绝。（路径与有效包测试通过，负例矩阵待补验）
- [ ] macOS 用户取消未保存文档关闭时不替换；旧进程超时、替换或启动失败有可验证的恢复行为。（启动失败回滚测试通过，其余待桌面验收）
- [ ] Windows 便携版与 MSIX、macOS Release Notes 和启动免打扰行为无回归。（既有测试通过，待实机）

- [x] 无未使用平台代码、调试输出、注释掉的旧实现或无界后台任务。
- [x] 所有新增缓存、staging、辅助文件、任务和锁均有容量与释放路径。
